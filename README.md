# Planeación Deportiva - I.E. Inocencio Chincá

Sistema de gestión para la organización, planeación y control de torneos deportivos escolares en la **Institución Educativa Inocencio Chincá**.

Esta aplicación fue reescrita en **React 19 + TypeScript + Vite + Tailwind CSS**, manteniendo intacta la lógica de torneos, datos oficiales, cronogramas por fases, equipos inscritos, resultados oficiales y esquemas de llaves de eliminación directa.

## Características

- **⚽ Deportes:** Consulta detallada de las 5 disciplinas deportivas oficiales (Fútbol, Baloncesto, Voleibol, Atletismo y Microfútbol), incluyendo escenario, modalidad, descripción y lista de equipos/atletas.
- **🗓️ Calendario:** Cronograma estructurado por fases (Cuartos de final, Semifinales, Gran Final y Series eliminatorias) con horarios, encuentros y clasificados/avances.
- **👥 Equipos:** Listado general de equipos y atletas registrados con capacidad de inscripción reactiva.
- **📊 Resultados:** Marcadores finales y estados oficiales de encuentros y podios atléticos, con persistencia en `localStorage` y opción de restablecer datos iniciales.
- **🏆 Esquema de Torneo:** Llaves de eliminación directa y avance de ganadores por deporte, con vista de tabla tradicional y diagrama visual interactivo con coronación de campeones.

## Tecnologías

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
